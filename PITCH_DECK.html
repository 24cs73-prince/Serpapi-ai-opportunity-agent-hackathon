Problem Statement

The Career Search Dilemma

Finding internships and early roles is fragmented, manual, and unguided.

❌ Scattered & Stale Data
Listings exist across dozens of job boards with stale details, expired deadlines, and unverified links.
❌ 15+ Hours Wasted Weekly
Candidates waste hours copying job specs, guessing eligibility, and applying blindly without fit feedback.
❌ Hidden Skill Gaps
Applicants don't know *which* missing technical skills are critical or what to learn first to qualify.
❌ Lack of Personalization
Traditional platforms display static listings completely detached from candidate background or preferences.

Agent Architecture

LangGraph Autonomous Workflow

Stateful multi-node orchestration guarantees deterministic execution & transparency.

🧠 Query Planning
Parses candidate goals and generates multi-engine search parameters for SerpApi.
⚙️ Data Normalization
Transforms raw JSON payloads into validated Pydantic v2 Opportunity models with deterministic IDs.
⚡ FAISS Vector RAG
SentenceTransformers embeddings index job text for semantic context retrieval.
🎯 Transparent Scoring
Weighted formula: 50% Skills, 20% Experience, 10% Education, 10% Location, 10% Preference.
Core Integration

Why SerpApi is Fundamental

SerpApi provides the live data backbone powering 100% of OpportunityIQ intelligence.

Google Jobs API
Fetches structured job titles, hiring company names, stipends, and direct apply URLs.
Google Search API
Retrieves company career portals, hackathon landing pages, and supplementary context.
Google News API
Tracks real-time hiring trends, tech stack shifts, and campus recruitment dates.
Personalization

Resume Parsing & RAG Intelligence

Combining multi-format document ingestion with vector search.

📄 Document Ingestion
Parses PDF (PyPDF2), DOCX (python-docx), and TXT files directly in-memory.
⚡ Vector Embeddings
Generates 384-dimensional dense vectors via `all-MiniLM-L6-v2` for semantic similarity search.
