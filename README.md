# OpportunityIQ

### Discover. Verify. Analyze. Act.

> AI-powered opportunity intelligence for discovering, matching, and analyzing jobs, internships, hackathons, and research opportunities.

OpportunityIQ is an AI-powered career intelligence platform that combines **live SerpApi search, LangGraph agents, RAG, semantic matching, skill-gap analysis, and opportunity ranking** into one workflow.

Instead of simply returning search results, OpportunityIQ helps users understand:

- Which opportunities match their profile
- Which skills they already have
- Which skills they are missing
- Why an opportunity is relevant
- Which opportunities deserve attention
- Where to find the application
